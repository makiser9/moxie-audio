# moxie-audio

Public static example-sentence audio assets for **Moxie (默写)**, downloaded on demand and cached locally in Cache Storage (`moxie-audio-remote`) so the iOS IPA remains compact while supporting offline playback after first listen.

- `ja/ja-JP-NanamiNeural/sentences/`: 8,271 JLPT N5–N1 example sentence clips synthesized with Microsoft Edge TTS (`ja-JP-NanamiNeural`).
